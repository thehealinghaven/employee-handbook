This is the short version of the legal audit behind the manual, verified in September 2026. It exists so you can see which rules bind the practice today, which ones start at a headcount we haven't reached, and where each one lives in the manual. The full cite table with sources is in the repository README for whoever maintains this.

The practice is Helen DeLovely LCSW PLLC, a Utah professional limited liability company owned by a licensed clinical social worker. As of September 2026 it has fewer than 15 employees. Where a law starts at 15, 20, or 50 employees, the manual applies the standard anyway by policy; what changes at the threshold is the legal remedy, not how we behave.

## When headcount changes

The practice manager re-checks this map whenever headcount crosses 10, 15, 20, or 50, and each January. Thresholds are counted the way each law counts them, which is usually 15 or more employees for 20 or more weeks in the current or prior year.
